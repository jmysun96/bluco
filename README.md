# Bluco 우리 아이 건강수첩

> 반려동물 생애주기 건강정보 웹앱 · 첫 버전(v1) 제품 요구사항 문서
> 작성일: 2026-10-17 · 상태: **승인 대기** (승인 전 코드 작성 금지)

---

## 1. 개요

### 1.1 한 줄 정의
강아지·고양이 보호자가 **생애 단계별 건강체크 항목, 적정 사료 급여량, 자주 생기는 질병**을 휴대폰에서 한 손으로 빠르게 확인하는 단일 HTML 웹앱.

### 1.2 배경
- 반려동물 정보는 블로그·커뮤니티에 흩어져 있고 출처와 정확도가 제각각이다.
- 특히 노령(시니어) 단계는 관리 항목이 급격히 늘어나지만, 보호자가 한눈에 볼 정리된 자료가 부족하다.
- 브랜드(블루코/Bluco)가 신뢰할 수 있는 정보 채널을 먼저 제공해 보호자와의 접점을 만든다.

### 1.3 대상 사용자
| 사용자 | 상황 | 기대 |
|---|---|---|
| 강아지·고양이 보호자 | 산책 중, 병원 대기 중, 사료 살 때 휴대폰으로 빠르게 확인 | 3번 이내 터치로 원하는 정보 도착 |
| 노령 반려동물 보호자 | 나이 들며 생기는 변화가 걱정됨 | 지금 챙겨야 할 검사·증상 신호 확인 |
| PC·태블릿 사용자 | 집에서 차분히 정보 읽기 | 넓은 화면에서도 보기 좋은 카드 배치 |

### 1.4 성공 기준
- **휴대폰에서 한 손(엄지)으로 모든 P0 기능을 사용할 수 있다.**
- 처음 쓰는 사용자가 안내 없이 1분 안에 사료 급여량을 계산할 수 있다.
- 360px 폭 휴대폰부터 PC까지 가로 스크롤 없이 보인다.

| 대상 동물 | 강아지·고양이 2종, **전 생애(어린 시기·성체·시니어)**, 시니어 단계를 가장 자세히 |
| 사료 급여량 | 체중·나이·상태 입력 → 하루 권장 칼로리와 급여량(g)을 계산하는 **계산기** |

## 3. 기능 요구사항

우선순위 정의
- **P0** — 첫 버전에 반드시 있어야 함. 없으면 출시 불가.
- **P1** — 첫 버전에 있으면 좋음. P0 완료·검증 후 진행.
- **P2** — 다음 버전 이후. 이번에는 만들지 않음.

### P0 — 필수

#### F1. 종·생애단계 선택
화면 상단에서 강아지/고양이를 고르고, 생애 단계(어린 시기 / 성체 / 시니어)를 고르면 아래 모든 정보가 그 기준으로 바뀐다.

- 생애 단계 기준(안내 문구로 표시)
  - 강아지: 어린 시기 ~1세 / 성견 1~7세 / 시니어 7세 이상 (대형견은 5~6세부터 시니어로 안내)
  - 고양이: 어린 시기 ~1세 / 성묘 1~10세 / 시니어 10세 이상

수용 기준
- [ ] 강아지·고양이 선택 버튼이 있고, 현재 선택된 쪽이 색으로 구분된다.
- [ ] 생애 단계 3개 중 하나를 선택하면 건강체크·질병 카드 내용이 즉시 바뀐다(새로고침 없음).
- [ ] 처음 열었을 때 기본값은 "강아지 · 성견"이다.
- [ ] 각 단계 버튼에 나이 기준이 함께 표시된다.

#### F2. 생애단계별 건강체크 카드
선택한 종·단계에서 챙겨야 할 항목을 카드로 보여준다. 카드마다 **무엇을 / 얼마나 자주 / 왜**를 담는다.

- 항목 예시: 예방접종, 심장사상충·구충, 치아 관리, 체중 측정, 건강검진(혈액·소변 검사), 관절 체크, 시력·청력, 행동 변화 관찰
- 시니어 단계는 검진 주기 단축(연 2회 권장), 신장·심장·관절·인지 변화 체크를 추가로 다룬다.

수용 기준
- [ ] 종 2개 × 단계 3개 = 6개 조합 모두 건강체크 카드가 4개 이상 있다.
- [ ] 시니어 조합은 카드가 6개 이상이며 다른 단계보다 항목이 많다.
- [ ] 모든 카드에 "주기"(예: 매일, 매월, 연 1회, 연 2회)가 눈에 띄게 표시된다.
- [ ] 카드는 휴대폰에서 1열, 태블릿 2열, PC 3열로 배치된다.

#### F3. 사료 급여량 계산기
체중과 상태를 입력하면 하루 권장 칼로리와 급여량을 계산한다.

계산 방식
- 기초 에너지 요구량(RER) = 70 × 체중(kg)^0.75
- 하루 필요 칼로리 = RER × 상태 계수

| 상태 | 강아지 계수 | 고양이 계수 |
|---|---|---|
| 어린 시기(4개월 미만) | 3.0 | 2.5 |
| 어린 시기(4개월~1세) | 2.0 | 2.5 |
| 성체 · 중성화 | 1.6 | 1.2 |
| 성체 · 중성화 안 함 | 1.8 | 1.4 |
| 시니어 | 1.4 | 1.1 |
| 체중 감량 필요 | 1.0 | 0.8 |
| 활동량 많음 | 2.0 | 1.6 |

- 하루 급여량(g) = 하루 필요 칼로리 ÷ 사료 칼로리(kcal/kg) × 1000
- 사료 칼로리는 포장지 표기를 입력하며, 기본값은 강아지 3,500 / 고양이 3,800 kcal/kg로 채워둔다.
- 결과에 "1일 2회 급여 시 1회 ○○g"을 함께 보여준다.

수용 기준
- [ ] 입력 항목: 체중(kg), 상태(위 표에서 선택), 사료 칼로리(kcal/kg). 종은 F1 선택을 따른다.
- [ ] 체중 입력 시 휴대폰에서 숫자 키패드가 뜬다.
- [ ] 검증 예시: 강아지 10kg · 성체 중성화 · 3,500kcal/kg → 하루 약 **630kcal**, 약 **180g**, 1회 약 **90g**.
- [ ] 검증 예시: 고양이 4kg · 성체 중성화 · 3,800kcal/kg → 하루 약 **238kcal**, 약 **63g**.
- [ ] 체중이 비었거나 범위 밖(강아지 0.5~90kg, 고양이 0.5~15kg)이면 계산하지 않고 한국어 안내 문구를 보여준다.
- [ ] 결과 아래에 "간식은 하루 칼로리의 10% 이내", "사료 포장지 권장량과 체중 변화를 보며 조절하세요" 안내가 있다.
- [ ] 결과 숫자는 정수로 반올림해 표시한다.

#### F4. 종별 주의 질병 카드
선택한 종에서 자주 생기고 신경 써야 할 질병을 카드로 보여준다. 카드마다 **주요 증상 / 잘 생기는 시기 / 예방·관리 / 바로 병원 가야 할 신호**를 담는다.

- 강아지(초안 목록): 치주질환, 슬개골 탈구, 피부염·알레르기, 비만, 이첨판 심장질환, 관절염, 만성 신장질환, 백내장, 인지기능장애
- 고양이(초안 목록): 치주질환, 하부요로질환, 비만, 만성 신장질환, 갑상선기능항진증, 당뇨병, 비대성 심근병증, 관절염
- 선택한 생애 단계와 관련이 큰 질병이 위쪽에 먼저 오고 "이 시기 주의" 표시가 붙는다.

수용 기준
- [ ] 강아지·고양이 각각 질병 카드가 8개 이상 있다.
- [ ] 카드는 기본으로 요약(질병명·한 줄 설명·주의 시기)만 보이고, 터치하면 상세 내용이 펼쳐진다.
- [ ] "바로 병원 가야 할 신호"는 다른 항목과 구분되는 강조 스타일로 표시된다.
- [ ] 시니어 선택 시 노령기 질병(신장·심장·관절·인지 등)이 목록 상단에 온다.

#### F5. 면책 문구와 공통 화면
- 정보 화면(F2·F3·F4) 하단에 "이 정보는 일반적인 참고용이며 진단이나 치료를 대신하지 않습니다. 이상 증상이 있으면 수의사와 상담하세요." 문구를 표시한다.
- 상단에 브랜드명(블루코 / Bluco)과 앱 이름을 표시한다.

수용 기준
- [ ] F2·F3·F4 각 화면에서 면책 문구가 보인다.
- [ ] 상단에 브랜드명이 보이고, 로고 이미지가 없을 때도 글자로 깨지지 않게 표시된다.

#### F6. 한 손 조작 화면 구성
- 휴대폰에서는 **하단 고정 탭바**로 "건강체크 / 사료계산 / 질병정보" 세 화면을 오간다.
- PC·태블릿에서는 같은 메뉴를 상단 또는 좌측에 표시해도 된다.

수용 기준
- [ ] 360px 폭에서 하단 탭바가 화면 아래에 고정되고, 엄지로 세 탭을 모두 누를 수 있다.
- [ ] 버튼·탭·카드 등 누르는 영역은 최소 48×48px이다.
- [ ] 자주 쓰는 조작(종·단계 선택, 계산 버튼)은 화면을 위로 끝까지 올리지 않고 닿는 위치에 있거나, 스크롤해도 닿는다.
- [ ] 본문 글자는 16px 이상, 가로 스크롤이 생기지 않는다.
- [ ] 휴대폰에서 탭 전환 시 화면 맨 위로 이동해 새 화면의 시작이 보인다.

### P1 — 있으면 좋음

#### F7. 우리 아이 1마리 등록
이름·종·생년월(또는 나이)·체중·중성화 여부를 입력해 브라우저(localStorage)에 저장한다. 다음에 열면 저장된 정보로 종·단계·계산기 입력이 자동으로 채워진다.

수용 기준
- [ ] 저장 후 새로고침해도 정보가 유지된다.
- [ ] 나이로 생애 단계가 자동 선택된다(F1 기준).
- [ ] 상단에 "○○의 건강수첩"처럼 이름이 표시된다.
- [ ] 정보를 지우는 버튼이 있고, 누르기 전에 확인을 묻는다.
- [ ] 저장소를 쓸 수 없는 환경(사생활 보호 모드 등)에서도 앱이 오류 없이 동작하고, 저장만 안 된다고 안내한다.

#### F8. 건강체크 완료 표시
건강체크 카드에 "했어요" 체크를 할 수 있고 기기에 저장된다.

수용 기준
- [ ] 카드마다 체크 버튼이 있고, 체크한 카드는 완료 상태로 보인다.
- [ ] 새로고침해도 체크 상태가 유지된다.
- [ ] 전체 체크를 한 번에 초기화할 수 있고, 초기화 전에 확인을 묻는다.

#### F9. 질병 검색
질병 화면 상단 검색창에 단어(예: "구토", "기침")를 입력하면 질병명·증상에 그 단어가 있는 카드만 보인다.

수용 기준
- [ ] 입력하는 즉시 결과가 걸러진다.
- [ ] 결과가 없으면 "검색 결과가 없어요" 안내가 보인다.

## 5. 디자인 요구사항

### 5.1 분위기
동물 일러스트가 들어간 **아기자기한 원색톤 카드**. 둥근 모서리, 부드러운 그림자, 밝고 친근한 느낌.

### 5.2 색상
| 역할 | 색 | 용도 |
|---|---|---|
| 메인 1 (코랄) | `#E8836B` | 주요 버튼, 선택 상태, 강조 |
| 메인 2 (네이비) | `#3A4F86` | 제목, 본문 강조, 하단 탭바 |
| 보조 원색 | 노랑 `#F6C85F` · 민트 `#6CC4A1` · 하늘 `#7FB8E6` | 카드 배경·아이콘 구분용 (메인색보다 적게 사용) |
| 배경 | 크림 `#FFF8F2` | 전체 배경 |
| 경고 | 진한 빨강 계열 | "바로 병원 가야 할 신호" |

- 코랄(`#E8836B`) 위 흰색 작은 글씨는 대비가 낮으므로, 코랄 바탕에는 **네이비 글씨 또는 굵고 큰 흰 글씨**만 쓴다.
- 본문 글자와 배경의 명도 대비는 4.5:1 이상을 지킨다.

### 5.3 동물 그림
- 외부 이미지 파일 없이 **HTML 안에 직접 넣은 그림(SVG) 또는 이모지**로 강아지·고양이를 표현한다.
- 카드마다 성격에 맞는 작은 동물 아이콘을 넣는다.

### 5.4 글꼴
- 기기 기본 한글 글꼴을 사용한다(인터넷 없이도 동일하게 보이도록). 외부 글꼴은 쓰지 않는다.

## 6. 기술 요구사항
- [ ] **HTML 파일 하나**(`index.html`)에 화면·스타일·동작을 모두 담는다.
- [ ] **설치 없이** 파일을 더블클릭하면 브라우저에서 바로 열린다.
- [ ] 외부 라이브러리·외부 글꼴·외부 이미지를 쓰지 않아 **인터넷이 없어도** 동작한다.
